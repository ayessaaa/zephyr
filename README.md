## Zephyr
**You have a very important mission, to save zephyr from falling.**

A 2d word game with rockets and balloons. Rockets will target zephyr's balloon, each rocket contains 2-4 letter word sequence that you must type a word including it. The longer the word, the better!

Play here: https://shaaarkai.itch.io/zephyr
